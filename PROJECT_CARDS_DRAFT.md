# Project Cards Draft

This file provides draft project cards for the academic homepage. These cards should be used to present only selected, strategically important projects rather than every repository.

## Selected Projects

### DroneVehicle

**Multimodal UAV-view vehicle detection with visible-infrared perception.**

DroneVehicle explores robust vehicle detection from drone-view imagery under small-object scale variation, background clutter, illumination changes, and cross-modality sensing conditions.

**Keywords:** RGB-T perception, UAV imagery, vehicle detection, multimodal fusion, small-object detection

**Repository:** `Hollis36/DroneVehicle`

---

### smolvlm-anti-drone

**Lightweight vision-language reasoning for anti-drone perception.**

This project studies whether small VLMs can support anti-UAV target verification, false-positive reduction, scene explanation, and human-interpretable decision support.

**Keywords:** anti-UAV, small VLM, target verification, reasoning-assisted detection, false-positive reduction

**Repository:** `Hollis36/smolvlm-anti-drone`

---

### VLM-UAV

**Vision-language models for UAV perception and semantic scene understanding.**

VLM-UAV focuses on UAV-specific VLM tasks, open-vocabulary perception, detector-VLM collaboration, explanation, annotation assistance, and reliability analysis.

**Keywords:** vision-language model, UAV perception, open-vocabulary sensing, semantic reasoning, multimodal foundation model

**Repository:** `Hollis36/VLM-UAV`

---

### robot-sim-vla-experiments

**Simulation experiments for robot learning and vision-language-action models.**

This repository supports embodied-intelligence experiments in simulation, including instruction-conditioned task execution, VLA policy evaluation, failure-case analysis, and sim-to-real preparation.

**Keywords:** robot learning, VLA, embodied intelligence, simulation, manipulation, sim-to-real

**Repository:** `Hollis36/robot-sim-vla-experiments`

---

### robotic-manipulation-learning

**Robot manipulation learning for perception-action systems.**

This project studies how robots connect visual perception, task understanding, policy learning, and action execution to perform manipulation under real or simulated constraints.

**Keywords:** robot manipulation, policy learning, affordance, embodied AI, perception-action learning

**Repository:** `Hollis36/robotic-manipulation-learning`

---

### abb-offline-coder

**Offline programming and code-generation tooling for ABB industrial robots.**

abb-offline-coder connects manufacturing task specifications, trajectory or process parameters, ABB program templates, validation, and industrial robot deployment workflows.

**Keywords:** industrial robotics, ABB, offline programming, code generation, smart manufacturing, robot deployment

**Repository:** `Hollis36/abb-offline-coder`

---

## Homepage Layout Suggestion

Use a two-column project grid with one short paragraph per project. Each card should include:

- Project title
- One-sentence contribution
- 3 to 5 keywords
- Code link
- Paper or project-page link, if available
- One figure, GIF, or schematic
